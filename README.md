# Fin Ars

Sodobna spletna stran arhitekturnega biroja **Fin Ars d.o.o.**

Temen, uredniški dizajn za telefon in računalnik: izbrani projekti s fotografijami, storitve, predstavitev biroja in kontakt.

## index.html

Samostojna datoteka, ki se odpre v brskalniku:

- Živa stran: https://tommyvimeo-gif.github.io/finars/
- Prenos: https://github.com/tommyvimeo-gif/finars/raw/main/index.html

## Lokalni zagon aplikacije

```bash
npm install
npm run dev
```

Stran se odpre na vratih 8080.
